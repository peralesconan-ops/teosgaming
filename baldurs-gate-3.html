🧙 RPG DE FANTASÍA

Baldur's Gate 3

Baldur's Gate 3 es un RPG de fantasía centrado en la exploración, las decisiones, la historia y los combates estratégicos.

Tus decisiones pueden cambiar el desarrollo de la aventura, las relaciones con otros personajes y diferentes situaciones durante el juego.

🎮 Género: RPG

🖥️ Plataforma: PC

💰 Precio: Juego de pago

👥 Multijugador: Sí

🎮 Sobre Baldur's Gate 3

Baldur's Gate 3 ofrece una aventura de rol en un mundo de fantasía donde los jugadores pueden explorar diferentes lugares, conocer personajes y tomar decisiones que afectan el desarrollo de la historia.

El sistema de combate utiliza elementos estratégicos y permite utilizar diferentes habilidades, personajes y estilos de juego para enfrentarse a los enemigos.

🖥️ Requisitos para PC

⚙️ Requisitos mínimos

Sistema operativo: Windows 10 de 64 bits

Procesador: Intel Core i5-4690 / AMD FX 8350

Memoria RAM: 8 GB

Tarjeta gráfica: NVIDIA GTX 970 / AMD Radeon RX 480

DirectX: Versión 11

Almacenamiento: 150 GB

🚀 Requisitos recomendados

Sistema operativo: Windows 10/11 de 64 bits

Procesador: Intel Core i7-8700K / AMD Ryzen 5 3600

Memoria RAM: 16 GB

Tarjeta gráfica: NVIDIA RTX 2060 Super / AMD RX 5700 XT

DirectX: Versión 11

Almacenamiento: SSD recomendado

¿Quieres mejorar el rendimiento?

Baldur's Gate 3 puede exigir bastante al ordenador. Ajustar correctamente las opciones gráficas y mantener actualizados los controladores puede ayudarte a conseguir un rendimiento más estable.

Si tienes un PC de gama media o baja, reducir algunas opciones gráficas puede ayudarte a mantener una tasa de FPS más estable.
