🎮 Sobre Metal Gear Solid V

El jugador controla a Venom Snake, un soldado que busca reconstruir su ejército y descubrir la verdad detrás de diferentes acontecimientos.

Las misiones se desarrollan en grandes zonas abiertas donde puedes decidir cómo enfrentarte a los objetivos.

Puedes utilizar sigilo, armas, vehículos, compañeros y diferentes herramientas para completar tus objetivos.

🎯 Características

Sigilo: Infiltrate en las bases enemigas evitando ser detectado.

Mundo abierto: Explora grandes escenarios y decide cómo completar las misiones.

Compañeros: Utiliza diferentes compañeros para obtener ventajas durante las misiones.

Mother Base: Construye y administra tu propia base, desarrolla equipamiento y recluta soldados.

🖥️ Requisitos para PC

⚙️ Requisitos mínimos

Sistema operativo: Windows 7/8/10 64-bit

Procesador: Intel Core i5-4460 o AMD FX-8350

Memoria RAM: 4 GB

Tarjeta gráfica: NVIDIA GTX 650 o AMD Radeon HD 7870

Almacenamiento: Espacio disponible para el juego

🚀 Requisitos recomendados

Sistema operativo: Windows 7/8/10 64-bit

Procesador: Intel Core i7-4790 o AMD FX-8350

Memoria RAM: 8 GB

Tarjeta gráfica: NVIDIA GTX 760 o AMD Radeon R9 280

Almacenamiento: SSD recomendado

💡 CONSEJO TEOS

¿Quieres completar las misiones sin ser detectado?

Observa primero las posiciones de los enemigos antes de entrar en una base.

Utiliza el entorno, las distracciones y tus herramientas para crear rutas seguras.

No siempre necesitas eliminar a todos los enemigos para completar una misión.
