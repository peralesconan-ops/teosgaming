🎮 Sobre DOOM Eternal

DOOM Eternal continúa la lucha del Doom Slayer contra las fuerzas demoníacas que amenazan la Tierra.

El juego recompensa el movimiento constante, la precisión y el uso inteligente de las diferentes armas y habilidades.

Durante la aventura tendrás que enfrentarte a grandes grupos de enemigos y poderosos demonios.

🎯 Características

Combate rápido: Muévete constantemente y utiliza diferentes armas para sobrevivir a los enfrentamientos.

Arsenal: Utiliza escopetas, rifles, armas de energía y diferentes herramientas de combate.

Demonios: Enfréntate a numerosos enemigos con diferentes habilidades y comportamientos.

Exploración: Descubre secretos, mejoras y objetos ocultos mientras avanzas por los niveles.

🖥️ Requisitos para PC

⚙️ Requisitos mínimos

Sistema operativo: Windows 10 64-bit

Procesador: Intel Core i5-4460 o AMD Ryzen 3 1200

Memoria RAM: 8 GB

Tarjeta gráfica: NVIDIA GTX 1050 Ti o AMD Radeon R9 280

Almacenamiento: Espacio disponible para el juego

🚀 Requisitos recomendados

Sistema operativo: Windows 10/11 64-bit

Procesador: Intel Core i7 o AMD Ryzen 7

Memoria RAM: 8 GB o más

Tarjeta gráfica: NVIDIA GTX 1060 o AMD Radeon RX 480

Almacenamiento: SSD recomendado
