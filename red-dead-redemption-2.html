🎮 Sobre Red Dead Redemption 2

La historia sigue a Arthur Morgan, miembro de la banda de Van der Linde, mientras el grupo intenta sobrevivir en un mundo que está cambiando rápidamente.

El jugador puede explorar enormes paisajes, pueblos, ciudades y diferentes regiones mientras descubre la historia.

Las decisiones, las relaciones con otros personajes y las actividades disponibles hacen que el mundo se sienta dinámico.

🎯 Características

Mundo abierto: Explora diferentes regiones del Viejo Oeste, desde pequeñas poblaciones hasta grandes paisajes naturales.

Historia: Sigue la historia de Arthur Morgan y la banda de Van der Linde.

Exploración: Descubre animales, lugares ocultos, personajes y diferentes actividades.

Caballos: Consigue, cuida y utiliza diferentes caballos para desplazarte por el mundo.

🖥️ Requisitos para PC

⚙️ Requisitos mínimos

Sistema operativo: Windows 10 64-bit

Procesador: Intel Core i5-2500K o AMD FX-6300

Memoria RAM: 8 GB

Tarjeta gráfica: NVIDIA GTX 770 o AMD Radeon R9 280

Almacenamiento: Espacio disponible suficiente para instalar el juego.

🚀 Requisitos recomendados

Sistema operativo: Windows 10/11 64-bit

Procesador: Intel Core i7-4770K o AMD Ryzen 5 1500X

Memoria RAM: 12 GB

Tarjeta gráfica: NVIDIA GTX 1060 6GB o AMD Radeon RX 480

Almacenamiento: SSD recomendado

💡 CONSEJO TEOS

¿Quieres disfrutar mejor de Red Dead Redemption 2?

No tengas prisa por completar la historia. Explorar el mapa permite descubrir eventos, personajes y lugares que pueden pasar desapercibidos.

También es recomendable mantener el equipo de Arthur y su caballo en buenas condiciones para facilitar la exploración.
