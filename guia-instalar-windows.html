Cómo instalar Windows

Aprende paso a paso cómo preparar un USB, instalar Windows y configurar correctamente tu PC después de la instalación.

🛠️ Antes de empezar

Antes de instalar Windows, asegúrate de tener todo preparado para evitar perder información importante.

  • Un PC compatible con Windows.
  • Una memoria USB de al menos 8 GB.
  • Una conexión a Internet.
  • Acceso a otro ordenador si necesitas crear el USB de instalación.
  • Una copia de seguridad de tus archivos importantes.

⚠️ IMPORTANTE: Una instalación limpia puede eliminar archivos de la unidad donde se instale Windows. Haz una copia de seguridad antes de continuar.

🔵 Paso 1 — Haz una copia de seguridad

Antes de modificar las particiones o instalar Windows, guarda tus documentos, fotografías, vídeos, partidas guardadas y cualquier otro archivo importante.

Puedes utilizar un disco externo o un servicio de almacenamiento en la nube.

No continúes hasta comprobar que tus archivos importantes están respaldados.

💾 Paso 2 — Prepara una memoria USB

Necesitarás una memoria USB con suficiente espacio para crear el instalador de Windows.

Conecta la memoria USB al ordenador que utilizarás para preparar el instalador.

⚠️ La creación del instalador puede borrar el contenido de la memoria USB.

🌐 Paso 3 — Descarga la herramienta oficial

Descarga la herramienta de creación de medios correspondiente a la versión de Windows que quieras instalar desde el sitio oficial de Microsoft.

Evita utilizar instaladores modificados o archivos ISO procedentes de páginas desconocidas.

🖥️ Paso 4 — Crea el USB de instalación

Ejecuta la herramienta oficial de creación de medios.

Sigue las instrucciones que aparecen en pantalla.

Cuando se solicite el medio de instalación, selecciona la memoria USB que vas a utilizar.

Espera mientras Windows descarga los archivos necesarios y prepara la memoria.

El proceso puede tardar dependiendo de la velocidad de Internet y de la memoria USB.

🔄 Paso 5 — Conecta el USB al PC

Cuando el USB esté preparado, conéctalo al ordenador donde quieres instalar Windows.

Enciende el ordenador y prepárate para acceder al menú de arranque.

⚙️ Paso 6 — Entra en el menú de arranque

Durante el encendido, algunos equipos permiten abrir el menú de arranque pulsando una tecla específica.

La tecla depende del fabricante de la placa base o del ordenador.

Algunas teclas habituales son:

  • F12
  • F11
  • F9
  • Esc

Si ninguna funciona, consulta el manual de tu placa base o equipo.

💾 Paso 7 — Selecciona el USB

En el menú de arranque, selecciona la memoria USB que acabas de preparar.

El ordenador debería iniciar desde el instalador de Windows.

🪟 Paso 8 — Inicia el instalador

Cuando aparezca el instalador de Windows, selecciona el idioma, formato de hora y distribución del teclado.

Después selecciona:

Instalar ahora

🔑 Paso 9 — Introduce la licencia

Si tienes una clave de producto válida, puedes introducirla cuando el instalador la solicite.

Si tu equipo ya dispone de una licencia digital asociada, puede existir la opción de continuar sin introducir la clave inmediatamente.

Utiliza siempre una licencia legítima.

💿 Paso 10 — Selecciona el tipo de instalación

Windows puede mostrar diferentes opciones de instalación.

Para una instalación limpia normalmente se utiliza la opción:

Personalizada: instalar solo Windows

⚠️ CUIDADO: No elimines ni formatees particiones si no estás seguro de qué contienen.

💽 Paso 11 — Selecciona la unidad

El instalador mostrará las unidades y particiones disponibles.

Identifica correctamente la unidad donde quieres instalar Windows.

Si estás realizando una instalación limpia, las particiones existentes pueden requerir cambios dependiendo de tu situación.

Si tienes varios discos conectados y no estás seguro de cuál es cuál, es mejor detenerte y comprobarlo antes de continuar.

⏳ Paso 12 — Espera la instalación

Después de seleccionar la unidad, Windows comenzará a copiar los archivos y preparar el sistema.

El ordenador puede reiniciarse varias veces durante este proceso.

No desconectes el equipo mientras Windows esté realizando la instalación.

👤 Paso 13 — Configura Windows

Cuando termine la instalación, Windows te pedirá configurar diferentes opciones.

Dependiendo de la versión y del dispositivo, pueden aparecer opciones relacionadas con:

  • Región.
  • Idioma.
  • Teclado.
  • Red Wi-Fi o Ethernet.
  • Cuenta de usuario.
  • Opciones de privacidad.

🔄 Paso 14 — Instala las actualizaciones

Una vez que estés dentro de Windows, conecta el ordenador a Internet.

Abre Windows Update y busca actualizaciones.

Instala las actualizaciones disponibles y reinicia el equipo cuando sea necesario.

🎮 Paso 15 — Instala los controladores

Instala los controladores necesarios para que todos los componentes funcionen correctamente.

Para un PC gaming presta especial atención a los controladores de:

  • Tarjeta gráfica.
  • Chipset de la placa base.
  • Red Ethernet o Wi-Fi.
  • Audio.

Descarga los controladores desde las páginas oficiales de los fabricantes.

🛡️ Paso 16 — Configura la seguridad

Mantén activadas las funciones de seguridad de Windows y utiliza software legítimo.

Evita descargar programas pirateados, activadores o archivos desconocidos.

🎮 Paso 17 — Prepara tu PC para jugar

Después de instalar Windows y los controladores, puedes comenzar a instalar tus plataformas y videojuegos.

También puedes revisar nuestras guías de optimización para mejorar el rendimiento del PC.

⚡ Mejorar rendimiento →

❌ Errores que debes evitar

  • No hacer una copia de seguridad.
  • Utilizar una ISO o instalador modificado de origen desconocido.
  • Seleccionar el disco equivocado.
  • Eliminar particiones sin saber qué contienen.
  • Desconectar el PC durante la instalación.
  • Instalar controladores desde páginas desconocidas.

💡 CONSEJO TEOS

Una instalación limpia de Windows puede dejar tu PC preparado para comenzar desde cero, pero no debes borrar particiones o archivos sin comprobar primero qué contienen.

Si tienes varios discos instalados, identifica cuidadosamente cada unidad antes de modificarla.
