Phasmophobia

Forma un equipo de investigadores paranormales y utiliza diferentes herramientas para encontrar pruebas sobre los fantasmas que habitan diferentes lugares.

🎮 Género Terror / Cooperativo / Investigación
🖥️ Plataforma PC
💰 Precio Pago
👥 Jugadores 1 - 4 jugadores

🎮 Sobre Phasmophobia

Phasmophobia es un juego de terror cooperativo centrado en la investigación paranormal.

Los jugadores forman parte de un equipo de investigadores que debe entrar en diferentes lugares para identificar qué tipo de entidad sobrenatural está presente.

Para conseguirlo tendrás que utilizar herramientas, buscar evidencias y mantener la calma mientras el fantasma se vuelve cada vez más peligroso.

🎯 Características

👻 Fantasmas: Existen diferentes tipos de entidades, cada una con comportamientos y evidencias particulares.

🔎 Investigación: Encuentra pruebas para determinar qué tipo de fantasma estás investigando.

🧰 Herramientas: Utiliza cámaras, sensores, lectores y otros equipos paranormales.

👥 Cooperativo: Trabaja con otros jugadores para completar las investigaciones.

😱 Cordura: Tu nivel de cordura puede disminuir durante las investigaciones.

🎙️ Comunicación: La comunicación y determinadas herramientas permiten interactuar con el entorno paranormal.

🔎 Investiga las evidencias

Durante cada investigación deberás buscar diferentes evidencias que permitan identificar al fantasma.

Las herramientas disponibles pueden ayudarte a encontrar temperaturas bajas, actividad paranormal, huellas y otras señales.

Comparar las evidencias encontradas es fundamental para determinar correctamente qué entidad estás enfrentando.

👻 Diferentes tipos de fantasmas

Cada tipo de fantasma tiene comportamientos y características diferentes.

Algunos pueden ser más agresivos, mientras que otros pueden reaccionar de maneras diferentes ante determinadas situaciones.

Aprender a reconocer estos patrones puede ayudarte a completar las investigaciones correctamente.

👥 Juega en equipo

Phasmophobia puede jugarse con amigos, formando un equipo de investigación paranormal.

Dividir las tareas puede hacer que la investigación sea más eficiente.

Mientras algunos jugadores buscan evidencias, otros pueden controlar cámaras, sensores o el equipo desde una zona segura.

😱 Cuando comienza la cacería

Las investigaciones pueden convertirse rápidamente en situaciones peligrosas.

Durante una cacería, el fantasma puede perseguir a los investigadores.

Encontrar un lugar seguro y mantener la calma puede ser fundamental para sobrevivir.

🖥️ Requisitos para PC

⚙️ Requisitos mínimos

Sistema operativo: Windows 10 64-bit

Procesador: Intel Core i5-4590 o AMD Ryzen 5 2600

Memoria RAM: 8 GB

Tarjeta gráfica: NVIDIA GTX 970 o AMD Radeon R9 390

Almacenamiento: 21 GB aproximadamente

🚀 Requisitos recomendados

Procesador: Intel Core i5 o AMD Ryzen 5

Memoria RAM: 16 GB

Tarjeta gráfica: NVIDIA RTX 2060 o equivalente

Almacenamiento: SSD recomendado

💡 CONSEJO TEOS

No te separes demasiado del equipo

Al comenzar una investigación, organiza las herramientas y decide quién se encargará de cada tarea.

No gastes todos los recursos demasiado rápido y presta atención a los cambios en el comportamiento del fantasma.

Si comienza una cacería, busca un escondite y evita hacer ruido innecesario.
